# YY CLUB 播客

YY CLUB 电台 52 期节目在线收听站。

**在线收听：** https://lvzhongpei.github.io/YY-CLUB/

## 特性

- 苹果极简设计风格，参考 Apple Podcasts 交互
- 实时音频频谱可视化（Web Audio API，渐变色随单集封面变化）
- 全屏播放器支持上一期 / 下一期直接切换，可一键收起到迷你播放条
- 倍速播放菜单（0.5× – 2× 六档点选）
- 响应式布局，适配 iPhone / iPad / Mac / PC
- 播放进度记忆、断点续播、搜索与排序
- 移动端锁屏/后台可持续播放，锁屏界面支持媒体控制
- 深浅色模式自动适配

## 技术

纯静态站点（HTML / CSS / JS），音频为 AAC 64kbps，托管于 GitHub Pages。
