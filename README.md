# YY CLUB 播客

YY CLUB 电台 52 期节目在线收听站。

**在线收听：** https://lvzhongpei.github.io/YY-CLUB/

## 特性

- 苹果极简设计风格，参考 Apple Podcasts 交互
- 实时音频频谱可视化（Web Audio API）
- AI 自动生成逐句字幕，同步高亮、点击跳转
- 响应式布局，适配 iPhone / iPad / Mac / PC
- 播放进度记忆、断点续播、倍速播放
- 深浅色模式自动适配

## 技术

纯静态站点（HTML / CSS / JS），音频为 AAC 64kbps，字幕为 WebVTT，托管于 GitHub Pages。
